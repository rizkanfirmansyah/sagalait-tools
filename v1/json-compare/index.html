Pembanding JSON

Tempel dua JSON, misalnya response API sebelum dan sesudah perubahan. Hasilnya menunjukkan key yang ditambah atau hilang, nilai atau tipe yang berubah, dan panjang array yang berbeda. Semua diproses di browser.

Opsi pembanding

Nama key (updated_at) berlaku di mana saja. Path seperti data.items[*].timestamp berlaku di lokasi itu saja. Tanda * mewakili satu nama atau satu indeks.

Urutan key di dalam objek selalu diabaikan, karena memang tidak berarti dalam JSON.
