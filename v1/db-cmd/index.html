Perintah database

Susun perintah terminal untuk MySQL, MariaDB, dan PostgreSQL: masuk, dump, pulihkan, dan lainnya. Tanpa kata sandi: klien selalu menanyakannya sendiri.

Apa yang ingin dilakukan

Koneksi

Kata sandi tidak diisi di sini dan tidak masuk ke perintah. Klien akan menanyakannya saat perintah dijalankan.

Lewat tunnel SSH (server database tidak terbuka ke luar)

Host dan port di atas dianggap alamat server database dilihat dari server SSH.
