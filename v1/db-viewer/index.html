Database viewer

Lihat data tabel dari CSV, JSON, dump SQL, atau keluaran terminal MySQL. Hanya untuk melihat: tidak ada koneksi ke database dan tidak ada SQL yang dijalankan.

Masukan

Data diproses di browser ini saja dan tidak disimpan. Ctrl+Enter di kotak teks untuk menampilkan. Yang diingat hanya pemisah dan pilihan judul kolom.

Langkah pertama: tempel data di kotak di atas atau pilih file, lalu tekan Tampilkan.

Ringkasan

Tabel

Beberapa filter digabung dengan AND. Sel NULL tidak cocok dengan berisi, sama dengan, lebih besar, dan lebih kecil; sel NULL cocok dengan tidak sama dengan.

Seret tepi kanan judul kolom untuk mengubah lebar, atau fokuskan tepinya lalu tekan panah kiri atau kanan.

NULL ditulis sebagai sel kosong di CSV dan TSV, dan sebagai null di JSON.

Tidak ada baris yang cocok dengan pencarian dan filter saat ini. Kosongkan kotak cari atau hapus filter.

Klik judul kolom untuk mengurutkan (naik, turun, tanpa urut). Klik sel untuk melihat nilai penuh, klik nomor baris untuk melihat satu baris.
